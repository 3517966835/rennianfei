# 任鸟飞逆向课程第四课：纯静态逆向与授权靶场实战
各位同学，欢迎来到《任鸟飞逆向课程》第四课开源靶场。本仓库提供了一个经过完全脱敏与重构的工业级加固 Native 样本——**任鸟飞逆向课程第四课授权靶场.so**。本节课的核心目标是摆脱对动态调试、App 运行环境以及 Frida 的依赖，纯粹通过**静态分析与二进制 Patch** 技术，彻底剥离远程鉴权与时间窗口校验，实现**无需登录直接使用**。
**核心技术要点**
 * **纯静态二进制剖析**：无需安装 APK 或配置动态调试环境，直接在 IDA Pro 或 Ghidra 中对单个 .so 文件进行交叉引用回溯与状态机还原。
 * **OLLVM 平坦化与控制流对抗**：学习如何应对被分发块打乱的汇编逻辑，精准定位控制流中的关键条件跳转（如 b.ne / b.eq）。
 * **Domain-Separated 校验链破解**：深入剖析基于 SplitMix64 混合常量的完整性校验机制与 Seqlock 状态机快照逻辑。
 * **硬编码 Patch 终极绕过**：掌握直接在汇编层将鉴权结果函数或标志位强制置真的修改技巧（如将函数首部直接 Patch 为 MOV W0, #1; RET）。
**仓库文件结构**
 * 任鸟飞逆向课程第四课授权靶场.so：本课核心演练目标二进制文件。
 * docs/static_analysis_guide.md：纯静态分析与 Patch 点定位的文字说明与寄存器上下文解析。
 * patch_tools/：辅助进行十六进制精准替换的参考脚本。
**动手实践指南**
 1. 将 **任鸟飞逆向课程第四课授权靶场.so** 拖入 IDA Pro 或 Ghidra 中进行静态加载。
 2. 从 JNI_OnLoad 或关键提示字符串入手，逆向回溯处理登录状态及有效期的底层核心函数。
 3. 针对阻断未登录状态的条件判断分支，通过十六进制编辑器或汇编 Patch 工具修改硬编码指令，达到本地免登录无条件放行的效果。
