# Android 安全实训靶场：Native 登录卡密静态逆向
本靶场专为高校安全课程、企业安全内训以及二进制安全爱好者设计，用于训练和评估在纯静态分析场景下对 Android Native 层（.so）进行逆向分析与漏洞挖掘的能力。
**实验目标**
 * 掌握 Android JNI（Java Native Interface）机制及 Native 函数的静态识别方法。
 * 熟练使用反编译工具（如 IDA Pro、Ghidra）阅读 ARM/ARM64 汇编与伪代码。
 * 培养在无动态调试环境、无源码支持的极端限制下，独立审计复杂校验逻辑与定位关键分支的能力。
**实验环境与工具**
 * **靶场载体**：target.so（闭源 Native 动态链接库）
 * **必备工具**：IDA Pro / Ghidra / Binary Ninja
 * **规则约束**：本靶场严禁使用动态调试、Frida、Xposed 或真机/模拟器运行。所有分析过程必须**纯静态**完成。
**任务要求**
 * **任务一（入口定位）**：在没有符号表或经过混淆的二进制中，准确定位卡密校验的核心逻辑入口（如分析 JNI_OnLoad 或静态注册表）。
 * **任务二（逻辑还原）**：阅读关键函数的控制流图（CFG）与反编译伪代码，逆向分析卡密的比对规则、加解密逻辑或状态判定条件。
 * **任务三（凭证推导 / 漏洞确认）**：推导出一组能够绕过卡密限制的有效输入，或者精准指出若要通过静态 Patch 绕过需要修改的具体字节。
